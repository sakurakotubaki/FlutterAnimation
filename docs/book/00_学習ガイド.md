# 00. 学習ガイド

この本の目的は、Flutter のアニメーションを「サンプルを真似する」段階から、「自分で設計できる」段階へ進めることです。

## この本で身につけたいこと

- `AnimationController` を自分で作って動かせる
- `vsync` や `Ticker` の意味を説明できる
- `Curve` と `Tween` の役割を分けて考えられる
- `AnimatedWidget` と `AnimatedBuilder` を使い分けられる
- `Hero` で画面遷移アニメーションを作れる

## Flutter アニメーションの基本原理

Flutter の明示的アニメーションは、次の 4 段階で考えると整理しやすいです。

1. **時間を進める**: `AnimationController`
2. **進み方を変える**: `Curve` / `CurvedAnimation`
3. **値に変換する**: `Tween`
4. **UI に反映する**: `AnimatedWidget` / `AnimatedBuilder` / `setState`

## まず押さえるべきこと

- `AnimationController` は「時間管理」
- `Tween` は「値の変換」
- `Curve` は「体感速度の調整」
- `Hero` は「ルート間の共有要素遷移」

この 4 つの役割を混同しないことが最初のポイントです。

## 学習のコツ

- 最初は **1 つの値だけ** を動かす
- 次に **サイズ + 不透明度** のように組み合わせる
- 最後に **画面遷移** とつなげる
- エラーが出たら「どの層の問題か」を切り分ける
  - `vsync` なら `TickerProvider`
  - 値変換なら `Tween`
  - 再描画なら `AnimatedWidget` / `AnimatedBuilder`
  - 画面間のつながりなら `Hero`
